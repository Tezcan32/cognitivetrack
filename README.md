# CognitiveTrack

A research prototype for tracking cognitive performance over time using
a digital Trail Making Test and short daily self-reports.

## Motivation
I'm a Neurocognitive Psychology MSc student. This project combines my
background in cognitive assessment with Python and data analysis to explore
whether repeated digital measures can reveal deviations from an individual's
typical performance.

## Status
Early development (started October 2026)

## Roadmap
- [ ] Python fundamentals & analysis notebooks
- [ ] Web-based Trail Making Test prototype
- [ ] Daily self-tracking and data collection
- [ ] Personal baseline & practice-effect analysis
- [ ] Interactive dashboard

## Disclaimer
This is a research/learning prototype, not a diagnostic tool.
